
# NEXORA — Responsive Landing Page

NEXORA is a modern, responsive landing page for a fictional digital creative studio. It showcases a clean layout, bold typography, interactive elements, and a unique midnight navy, electric violet, and mint green color palette.

## Features

- Responsive navigation bar with a mobile hamburger menu.
- Hero banner with gradient typography and abstract CSS artwork.
- Call-to-action buttons with hover effects and smooth transitions.
- Services section featuring three service cards.
- Project call-to-action section, about section, and footer.
- Responsive layouts using CSS Grid and Flexbox.
- JavaScript-powered mobile navigation.
- Automatic copyright year update.
- Keyboard accessibility and reduced-motion support.
- Responsive breakpoints for desktop, tablet, mobile, and small phones.

## Technologies Used

- HTML5 — Website structure and semantic elements.
- CSS3 — Styling, Flexbox, Grid, animations, transitions, and media queries.
- JavaScript — Mobile menu interactions and dynamic copyright year.

## How to Run the Project

1. Download or clone the project folder.
2. Ensure all four files are in the same directory.
3. Open `index.html` in a web browser.
4. Use the navigation links to explore the different sections.
5. Resize the browser window to check the responsive layout.

No package installation or build tools are required.

## Responsive Design

The landing page supports the following target viewport sizes:

| Device | Viewport | Expected Layout |
|---|---|---|
| Desktop | 1440 × 900 | Two-column hero and horizontal navigation |
| Tablet | 768 × 1024 | Compact hero and adjusted spacing |
| Mobile | 390 × 844 | Single-column hero and hamburger menu |
| Small phone | 320 × 700 | Compact typography and stacked buttons |

These are intended test sizes. Verify the rendered page in a browser at each viewport.

## Responsive Testing

To test the design in Google Chrome:

1. Open `index.html`.
2. Open Developer Tools using `F12`.
3. Enable the device toolbar using `Ctrl + Shift + M`.
4. Test the desktop, tablet, mobile, and small-phone viewport sizes listed above.
5. Check the navigation menu, CTA links, card layout, hover effects, and horizontal overflow.
